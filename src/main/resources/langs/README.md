# RAS Plugin Language Files

Dieses Verzeichnis enthält alle Sprachdateien für das Plugin "Remove All Scoreboards".  
Jede Sprache hat einen eigenen Abschnitt mit Hinweisen, Platzhaltern und Beispielen.

---

## Deutsch (de.lang)

- Jede Datei endet mit `.lang`
- Key=value Paare, die vom Plugin intern genutzt werden
- Platzhalter:
    - `{whitelist}` → aktuelle Whitelist
    - `{objective}` → jeweiliges Objective
- Beispiel:  
  `warning=Vorsicht! Tippe /ras erneut innerhalb von 5 Sekunden, um wirklich alle Scoreboards zu löschen. Whitelist: {whitelist}`

---

## Englisch (en.lang)

- Each file ends with `.lang`
- Key=value pairs used internally by the plugin
- Placeholders:
    - `{whitelist}` → current whitelist
    - `{objective}` → respective objective
- Example:  
  `warning=Warning! Type /ras again within 5 seconds to really remove all scoreboards. Whitelist: {whitelist}`

---

## Japanisch (jp.lang)

- ファイルはすべて `.lang` で終わります
- key=value のペアはプラグイン内で使用されます
- プレースホルダー:
    - `{whitelist}` → 現在のホワイトリスト
    - `{objective}` → 対応するオブジェクト名
- 例:  
  `warning=注意！5秒以内にもう一度 /ras と入力すると、すべてのスコアボードが本当に削除されます。ホワイトリスト: {whitelist}`
